# C-assignment-2
Create a custom library stringtoolkit.h containing the following functions:

void to_uppercase(char str[]); — Converts a string to uppercase.

void to_lowercase(char str[]); — Converts a string to lowercase.

int count_vowels(const char str[]); — Counts the number of vowels in a string.

void reverse_string(char str[]); — Reverses the characters of a string.

void sort_strings(char arr[][100], int n); — Sorts an array of strings alphabetically.

void reverse_words(char str[]); — Reverses the order of words in a string.
